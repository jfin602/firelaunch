# FireLaunch Known Issues

Bootstrap status only.

No product implementation exists at 0.0.0. The active P0 Prompt Stack is responsible for the first implementation.

Expected qualification risks:
- Vega SDK/toolchain may not be installed in the implementation environment.
- A real Bedrock call requires valid AWS credentials and a configured model ID.
- Simulator/device qualification is environment-dependent and cannot be replaced by browser preview.
- Amazon Developer Console submission remains a human-authenticated external step for the Vega MVP.
