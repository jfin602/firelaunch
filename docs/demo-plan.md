# FireLaunch Three-Minute Demo Plan

The video should prove the whole thesis, not tour every control.

## Story

A wildlife filmmaker wants a channel named Wild Earth.

## Target sequence

0:00-0:15
State the problem and show an empty/new FireLaunch project.

0:15-0:40
Prompt:
"Build Wild Earth. Make it cinematic. Feature the newest film, then Nature, Oceans and Africa."

Show TV preview materialize from ChannelSpec.

0:40-1:05
Use virtual remote/keyboard to navigate hero, rails, detail and playback. Focus is visible.

1:05-1:30
Ask:
"Make Oceans the first rail and use a cooler visual treatment."

Show preview update and change activity.

1:30-1:50
Open Code. Show an ordinary React Native for Vega project and editable source.

1:50-2:15
Open Build. Show toolchain/readiness checks and a real successful VPKG build or already-qualified artifact.

2:15-2:40
Run the generated app on Vega simulator or Fire TV. Navigate the same channel.

2:40-2:55
Open Publish. Show submission assets/checklist and remaining human Amazon Console step.

2:55-3:00
End on:
"Describe your channel. Launch it on TV."

## Recording rule

Do not use fake simulator footage. The TV-runtime portion is the actual generated app in an accepted Fire TV/Vega environment.
