## P1 — Template model and page creation

Use `packages/contracts/src/index.ts` existing hero/rail/grid/text (no module schema change here); `packages/channel-engine/src/index.ts` page add/starterChannel; current App Channel `Content` entry. Add deterministic validated `createPageFromTemplate(name,choice)` or equivalent helper so `addPage` receives the complete page plus starter modules **in one mutation** with stable page/module IDs. Home in **newly created channels only** starts Hero; existing stored Home pages must not be retroactively modified. New page UI asks name+Hero/Grid/Rows with visual preview, Rows preselected; retained form state after failure, no duplicate retry, cancel/focus return. Empty modules have honest "Choose content" placeholders in editor; no fabricated owner content or live publication. Test all templates, old-project no mutation, IDs/retry, strict bounds/ownership.

## P2 — First-class Page layout workspace

Rename **Pages & Shelves** → **Pages & Layout** under Channel, retaining the same route/workspace and existing mutations. Organize pages list (clear selected, New, Rename, Delete), large central page composition and Wave 1 contextual-only inspector (no permanently allocated empty right rail). Use the real preview/TV semantics, not a second channel representation; authoring can show overlay selection controls but must not alter actual published TV. Distinguish editor draft from live published release; preserve project selection, controlled form/focus after route and page switch, accessibility and responsive dimensions. Move low-level page/film controls out of the primary happy path without deleting functionality; refer actual catalog selection to Library. Test project/account switch and no empty inspector.

## P3 — Section controls and progressive customization

Make existing Hero/Row/Grid/Text Area discoverable in **Add Section** and editable through common controls: Choose content, Edit text, Move up/down, Rename heading, Customize (collapsed). Reuse existing `addModule/updateModule/reorderModules/removeModule` and revision guards. Media selections use owner-owned content, valid rights; no unsafe URL entry or fake published status. Provide truthful saving/error feedback and recover unsaved drafts. Keyboard move controls are fully operable even if optional drag handles exist; avoid destructive template replacement without explicit content preservation/diff. Safe limits of content/section counts, last-page protections, deletion does not remove shared Library assets. Style presets for existing sections may be added only if a single typed contract also reaches the TV runtime (prefer defer preset expansion to P4/P5). Focused mutation/editor tests.

## P4 — Static image/text sections and safe contract evolution

Add minimal `image-banner` and `image-text` (exact names selected against codebase) `moduleSchema` variants, with title/body/image and only bounded, enumerated style fields (crop, alignment, image side/background/spacing as needed). Preserve strict validation, IDs, max lengths, existing saved `schemaVersion=1` ChannelSpec acceptance and old published release readback. No arbitrary executable layout, unlicensed stock art or unrestricted private artwork URLs. Update channel-engine code that assumed `module.kind !== 'text'` implies `contentIds`, including `removeContent` and content resolution. Update packages/tv projection and Studio Preview with static and mixed sections, non-focusable text/image, no crash with empty content. Add selection/editor controls for new modules with human names, existing owned asset/rights policy. **Do not publish or build native yet**; P5 owns native/projection guard. Test schema/roundtrip, invalid/missing/private assets, old specs, stable ordering and non-interactive focus rows.

## P5 — Native Vega projection and installed-client compatibility

## P6 — Same-instance full-screen TV Preview

Refactor/scope `apps/studio/src/Preview.tsx` and Channel toolbar minimally so **View full screen** enlarges the exact existing TV state and player, preserving page, D-pad focus, playback, editor page selection/scroll and any unsaved edits.
