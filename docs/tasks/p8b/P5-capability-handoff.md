# P5 installed layout capability handoff

The generated Vega source renders Image Banner, Image + Text, and the bounded hero, row, grid, and text presets from the shared TV projection. This is source and focused test evidence only. P7 still owns an independent installed native rendering check for the changed layout.

The current deployment record binds a package ID and creator approval, while native build evidence binds an artifact to an existing published release. Neither records an installed package's supported module kinds or presets. A package name, ChannelSpec schema version 1, or a newer generated template cannot prove that an already-installed client has this renderer. The C7 R4 package predates these sections.

For that reason, approval, Publish Now, and manifest projection reject Image Banner, Image + Text, and any new presentation preset with **Requires App Update**. Existing releases and old ChannelSpec v1 layouts remain readable. This gate stays in place even when a newer package is generated locally.

Phase 9 must bind verified native artifact identity and installed runtime capabilities to each deployment, qualify the upgrade on the installed client, and only then permit a compatible data-only publication. Preserve the currently approved free release and the existing owner, revision, rights, and public media checks throughout that work.
