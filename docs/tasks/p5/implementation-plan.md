## P4 — Public HTTPS resolver / 0.5.4

Implement strict read-only sanitized public route(s) resolving opaque deployment ID live pointer and immutable release by id through publishedManifestSchema parsing. Separate from authenticated creator routes, only expose data explicitly approved/published; never leak drafts, creator PII, S3 private object keys, ephemeral signed URLs, original source records or code. Bounded bytes/rate/path and correct MIME/ETag/cache controls; pointer fresh, immutable revisions cacheable, provenance hashes verifiable with pinned HTTPS origin. Use TLS boundary appropriate for a **controlled temporary staging endpoint** without opening local legacy/no-auth APIs or creator writes to the public internet. Tests: GET public signed-out success and unchanged immutability, foreign/invalid/unpublished 404, injection/oversized/revoked unauthorized source, no private endpoint access, concurrency+restoration. Document staging preflight without provisioning an unrequested VPS.
