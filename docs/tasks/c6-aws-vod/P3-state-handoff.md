# P3 managed encoding and publication handoff

Root remains `0.6.7`. This is offline implementation evidence only; no MediaConvert job, AWS stack, CDN fetch or Vega playback was run.

The authenticated upload finalize path now streams a full original SHA-256 check before enqueue, reserves one durable managed intent with cleared playback rights, a fixed checked-in 480p/720p profile, two concurrent creator slots, 120 claimed minutes per rolling day and three total attempts. The control plane submits directly to MediaConvert under a narrowly scoped proposed IAM policy. P2's Lambda proposal was replaced in the **review-only** overlay with private EventBridge-to-SQS delivery because the Lambdas had no authenticated Postgres intent access. Events are hints; GetJob plus registered intent, account, Region, queue, role, input/output paths, profile hash and output details must agree. Missed events are polled; lost CreateJob responses are searched by bounded ListJobs and never blindly submitted again. Provider COMPLETE leaves media pending until private HLS playlists and all segments are bounded, hashed, normalized into immutable staging and accepted by an owner/rights/attempt checked READY transaction. P5 approval, promotion, v1 manifest URL and revocation remain the sole publication route. Existing READY renditions are untouched.

P4 should retire production FFmpeg routing only after reviewing this new path, wire operational status/retry messaging, and add an operator inventory for orphan private staging. The 2 GB full SHA-256 read currently runs in the API finalize process and may be too heavy for the intended small web host; move it to a capacity-controlled verification process before live activation. Verify actual MediaConvert acceptance, returned output metadata/MIME, and all bucket/OAC policies with an operator-reviewed change set before enabling the paused queue/rule. Claimed duration is not a trustworthy cost probe; add an authoritative duration guard or restrictive processing policy before paid work. P4 must not claim real AWS, live publication, Vega or P6 GREEN from the offline tests.
