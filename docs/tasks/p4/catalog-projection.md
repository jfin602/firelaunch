# P2 catalog projection boundary

`CatalogProjectionService` is an internal, read-only input for later channel composition. It accepts an authenticated principal, owned project ID, explicit item and collection IDs, and expected project/catalog revisions. The hosted project and catalog repositories verify the principal against the stored identity and ownership. Foreign and missing IDs fail closed; selected collection membership is resolved from the owned inventory. A second revision read rejects a stale candidate. The eventual ChannelSpec write must still use the hosted project's revision compare-and-swap.

Three distinct decisions apply:

1. **Review/approval:** `catalog_item_approvals` records a completed import approval or direct creator entry. A preview, discovered source, or existing item row alone is insufficient. Migration 008 cannot infer approval of older items, so those items need a fresh explicit import approval before projection. Reapproval of unchanged rows records the approval and advances the catalog revision.
2. **Selection:** The creator explicitly chooses item and collection IDs for this projection. Approval does not automatically place anything in a channel. Bindings use a deterministic content ID from the catalog item ID and return the safe projected baseline with its selected collection associations. P3 must retain that baseline when it applies content so later regeneration can compare it against creator edits.
3. **TV use:** Actual artwork requires linked delivery-eligible artwork with cleared television display rights; actual video/audio requires linked delivery-eligible media of the matching type with cleared television playback rights. Unknown or revoked rights never yield a media URL. Source permission revocation blocks the item. ASINs, source artwork URLs and uploads do not imply a license. Only stable HTTPS asset locations without query or fragment enter the candidate; private objects and signed URLs stay server-side. A book can remain informational with a neutral unresolved artwork placeholder and no playback URL.

The projection returns allowlisted title, description, presentation, artwork and playback fields. It never copies raw source records, external identifiers, evidence references, private object IDs or media capabilities into the candidate. It does not mutate the catalog, persist a ChannelSpec, issue private media access, or expose a browser API in P2. Draft Preview access and applied binding persistence belong to later P4 checkpoints; public TV delivery belongs to P5.
